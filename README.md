## 🚀 Featured Projects

### 1. StudentIQ – Student Performance Analytics

A full-stack Machine Learning application designed to analyze student-related academic, personal, and social attributes to identify students who may be academically at risk.

**Key Features:**
- Student information-based risk prediction.
- Estimated academic risk probability.
- Interactive React-based analytics dashboard.
- Machine Learning model evaluation and performance metrics.
- REST API integration using FastAPI.
- Deployed frontend and backend using Render.

**Machine Learning:**
- Dataset: UCI Student Performance Dataset.
- Models: Logistic Regression, Random Forest, Dummy Classifier.
- Model selection using cross-validation.
- Evaluation using Accuracy, F1-score, and ROC-AUC.

**Tech Stack:** Python, Pandas, NumPy, Scikit-learn, FastAPI, React.js, Vite, Joblib, Pytest, Render.
